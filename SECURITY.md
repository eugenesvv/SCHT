# Security policy

## Supported version

Security fixes are applied to the latest public test release. The current public test version is 1.6.0.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository when it is available. Do not open a public issue for a vulnerability that could expose users or their data.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not attach real `Game.log` files, SCHT AppData, OCR reports, or screenshots containing player details; provide the smallest sanitized sample needed to reproduce the issue.

SCHT runs locally and reads user-selected game logs. Reports involving file handling, the local web interface, exported manifests, installer behavior, or unintended data disclosure are especially useful.
