SCHT 1.5.66 first public test-release packaging patch

- Rebased the visible/public version from 3.5.66 to 1.5.66.
- Opens the main window wider and keeps the primary toolbar on the Game.log row at normal desktop widths.
- Renamed AppData to %LOCALAPPDATA%\SCHT with automatic migration from the legacy folder.
- Added an Inno Setup installer and clean uninstaller for app files, shortcuts, current AppData, and legacy AppData.
- Added local and GitHub builders for both SCHT.exe and SCHT-Setup-1.5.66.exe.
- Clarified that end users do not need Python; the standalone EXE bundles its runtime.

Apply these files over SCHT 3.5.66, rebuild SCHT.exe, then run build_installer.bat on Windows with Inno Setup 6 installed.
