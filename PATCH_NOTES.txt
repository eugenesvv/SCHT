SCHT 1.5.66 — first public test release

- Tracks accepted, completed, and abandoned Star Citizen hauling contracts from Game.log.
- Adds a session dashboard, Logistics Board, loading checklist, compact overlay, timer, filters, and CSV/HTML exports.
- Includes OCR-assisted contract detail recovery with manual review and correction tools.
- Provides a per-user Windows installer and clean uninstaller.
- Stores app-owned data under %LOCALAPPDATA%\SCHT and migrates the legacy data folder automatically.
- Ships as a standalone Windows application; Python is not required.

Recommended download: SCHT-Setup-1.5.66.exe

The portable SCHT.exe is also provided for users who prefer not to install the application. SHA256SUMS.txt contains checksums for both downloads.
